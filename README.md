# AI_Research

This repository is for our research project about using generative AI tools. I organised the files into different folders so they are easier to find.

The literature review folder contains papers and reading materials. Survey data and analysis files are in Quantitative_Analysis, while interview files are in Qualitative_Analysis. Drafts and reports are stored in Drafts_and_Reports, and images and other files are in Additional_Materials.

When adding new files, please put them in the related folder and use a clear file name and commit message.
